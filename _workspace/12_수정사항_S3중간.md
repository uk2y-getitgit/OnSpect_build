## F1. 도면 사이즈 통일 — A4 비율 정규화

> *"불러온 PDF, JPG 크기에 상관없이 비율조정 (a4가로)"*

### Numdraw 실측 방식 (그대로 이식)

```
150 DPI 고정.  A4_PX_MM = 150 / 25.4 ≈ 5.906 px/mm

A4.portrait  = 1240 × 1754 px
A4.landscape = 1754 × 1240 px
```

원본 이미지를 **A4 캔버스에 contain 배치**하고, 그 A4 캔버스를 도면으로 삼는다.

```
_calcFitRect(natW, natH, a4w, a4h):
  pxMm = a4w / (가로면 297 : 210)
  mPx  = round(10 * pxMm)      // 상하좌우 10mm 여백
  tbPx = round(20 * pxMm)      // 하단 도곽 20mm 예약
  avW  = a4w - 2*mPx
  avH  = max(10, a4h - 2*mPx - tbPx)
  scl  = min(avW/natW, avH/natH)          // contain, 비율 유지
  w,h  = round(natW*scl), round(natH*scl)
  x,y  = mPx + (avW-w)/2, mPx + (avH-h)/2  // 중앙 배치
```

배경은 흰색으로 채운다. 결과를 `imgLayout = { offX, offY, dW, dH }` 로 함께 보관한다.

### 우리 프로젝트에 맞춘 결정

- **방향: A4 가로 고정** (사용자 명시). Numdraw 는 `natW > natH` 로 자동 판별했으나,
  사용자가 "a4가로"로 못박았으므로 **landscape 1754×1240 고정**으로 간다
- **정규화 좌표(불변식 #1)와 충돌하지 않는다.** 오히려 모든 도면이 같은 종횡비가 되어
  `Phase 3` 의 각도 스냅 함정(종횡비별 왜곡)이 구조적으로 사라진다
- 기존에 등록된 도면은 **다시 정규화하지 않는다.** 새로 올리는 것부터 적용하고,
  기존 도면에는 `[A4로 맞추기]` 를 제공한다. 좌표가 정규화라 결함 위치는 유지된다

## F2. 표기 도구 동작 정리

> *"점선택시 번호바로 추가 확인, 화살표 점동작과 같음(모양만 화살표),
>  그리기는 자유그리기 후 결함번호 선택 또는 추가. 메모→자유그리기처럼 동작(필기메모),
>  구분은 확실하게"*

| 도구 | 동작 | 결함 연결 |
|---|---|---|
| **점** | 클릭 → 즉시 결함 생성 + 번호 부여 | 자동 |
| **방향(화살표)** | **점과 동일하게 동작.** 모양만 화살표 | 자동 |
| **영역** | 드래그 | 자동 |
| **그리기** | 자유곡선을 그린 **뒤** 결함번호를 고르거나 새로 추가 | **사후 선택** |
| **메모** | **자유그리기처럼 필기.** 텍스트 입력이 아니라 손글씨 | 없음 (독립) |

### 바뀌는 것

1. **화살표를 드래그 생성에서 점 방식으로 변경.** 현재 S2a 는 드래그(꼬리→머리)인데,
   사용자는 점과 같은 클릭 동작을 원한다. 방향은 기본값을 주고 나중에 조정하게 한다
2. **그리기의 결함 연결을 사후 선택으로 변경.** 현재는 "선택된 결함이 없으면 안내"인데,
   그리고 나서 `[결함 선택]` / `[새 결함으로]` 를 고르게 한다 (Q16 재결정)
3. **메모를 텍스트 입력에서 필기(자유곡선)로 변경.** 현재 S2a 는 노란 텍스트 상자다.
   사용자는 **손글씨 메모**를 원한다

### 그리기 ≠ 메모 — 구분을 확실히

둘 다 자유곡선이라 **시각적으로 반드시 달라야 한다.**

| | 그리기 | 메모 |
|---|---|---|
| 소속 | 결함에 종속 | 독립 |
| 색 | 결함 상태색을 따름 | **중립색** (결함 예약색 금지) |
| 선 | 실선 | 다른 질감 (굵기·투명도·점선 중 택1) |
| 출력 | ON/OFF 체크박스 | **별도** ON/OFF 체크박스 |

출력 ON/OFF 는 Phase 4 다. 다만 **데이터에 구분이 남아 있어야** 나중에 갈라 쓸 수 있다.

## F3. 우측 사이드바 — 결함정보 입력 + 좌표 숨김

> *"결함추가시 우측 사이드바에서 결함정보 입력버튼이 아직 구현되지 않음. (S4구현 예정)
>  (도면좌표, 풍선위치는 노출되지 않도록)"*

- **S4 에서 결함정보 입력 폼을 이 자리에 붙인다**
- **`도면 위치` 섹션(마크 좌표 · 번호 풍선 좌표)을 화면에서 제거한다.**
  정규화 좌표는 내부 구현이지 사용자가 볼 것이 아니다. 개발 중 확인용이었다

## F4. 다른 도구 선택 중에도 번호 풍선 이동 유지

> *"화살표, 영역, 그리기, 메모가 선택되어도 번호풍선 클릭하여 이동기능 유지"*

**어떤 도구가 활성이든 번호 풍선은 항상 잡히고 끌린다.**

히트 테스트 우선순위에서 **번호 라벨을 도구와 무관하게 최상위**로 둔다.
지금은 `선택` 도구일 때만 잡히는 것으로 보인다.

- 풍선 위에서는 커서가 `move` 로 바뀌어 "지금 이건 끌 수 있다"를 알린다
- 풍선을 끌면 스마트 정렬·각도 스냅이 그대로 동작한다
- 풍선이 아닌 곳에서는 현재 도구의 동작(점 찍기·영역 그리기 등)이 그대로 유지된다

## F5. Numdraw 이식 — 도곽 · 범례 · 도면크기 · 도면영역

> 원본은 로컬에만 있다. **아래 실측 명세로 구현하면 원본이 필요 없다.**

### F5-1. 도곽 (TitleBlock)

A4 캔버스 전체에 그린다. `tbScale` 로 전체 크기를 비례 조정한다.

```
기준값 (tbScale = 1)
  margin  = 20px      외곽 여백
  borderW = 1.5px     선 굵기
  blockH  = 68px      표제란 높이

설정값
  projectTitle   문자열
  drawingName    문자열
  scale          문자열 (기본 'NONE')
  col0 = 0.42    PROJECT TITLE 열 비율
  col1 = 0.46    DRAWING NAME 열 비율
                 (나머지 = SCALE 열)
  labelFontSz = 10    라벨 글씨
  valueFontSz = 14    내용 글씨
```

**렌더 순서**
1. 외곽 테두리 — `strokeRect(M, M, W-2M, H-2M)`
2. 표제란 영역 — 외곽 **하단**에 높이 `BH` 로 붙임. 흰색 채움 + 상단 구분선
3. 열 3개 — `c0 = bw*col0`, `c1 = bw*col1`, `c2 = 나머지`. 세로 구분선 2개
4. 셀 렌더
   - 일반 셀: 라벨(좌상단, 회색 `#666`, 600 weight) + 값(가운데 정렬, `#111`, 700 weight)
     값은 **최대 2줄로 줄바꿈**, 넘치면 `…` 로 자름
   - SCALE 셀: 라벨·값 모두 **가운데 정렬**, 값은 셀 높이의 62% 위치

**열 비율 보정**: `col0 + col1 > 0.90` 이면 `col1 = max(0.05, 0.90 - col0)` 로 자동 조정.
SCALE 열이 사라지는 것을 막는다.

**출력 시 ON/OFF** — 사용자 명시: *"도곽은 추후 출력시 on,off로 대응예정"*.
지금은 설정과 렌더만 만들고, 출력 옵션은 Phase 4.

### F5-2. 범례 (Legend)

**우측 상단**에 `기호 | 설명` 2열 표로 그린다. `lgScale` 로 비례 조정.

```
기준값 (lgScale = 1)
  fontSize = max(9, round(12 * lgScale))
  padX     = round(10 * lgScale)
  rowH     = round(24 * lgScale)
  margin   = round(30 * lgScale)
```

**레이아웃**
```
symW  = max(28*lgScale, 기호 최대폭) + padX*2
descW = 설명 최대폭 + padX*2
boxW  = symW + descW
boxH  = 행수 * rowH
bx    = canvasW - margin - boxW     // 우측 정렬
by    = margin
```

**렌더**
- 배경 `rgba(255,255,255,0.95)` — 반투명 흰색이라 도면 위에서 글씨가 읽힌다
- 기호가 있으면 기호 텍스트(가운데), 없으면 **그 색 가로선 샘플**을 그린다
- 설명은 좌측 정렬, 기호열 오른쪽에서 `padX` 띄움
- 괘선: 외곽 + 행 구분선 + 열 구분선 1개, `rgba(0,0,0,0.65)`

**우리 프로젝트에서의 행 구성**
Numdraw 는 장비/카테고리였다. OnSpect 는 **결함유형**이 행이 된다 —
`{ color: 결함유형 색, sym: '', desc: 결함유형 이름 }`.
기호가 없으므로 색상 선 샘플 경로를 탄다.
현재 도면에 **실제로 쓰인 결함유형만** 표기한다 (Numdraw 의 `equipFilter` 에 해당).

### F5-3. 도면 크기 조절

```
MIN_SCALE = 0.3, MAX_SCALE = 2.5
clampScale(v) = max(0.3, min(2.5, Number(v) || 1))
```

**중요**: Numdraw 주석 — *"배율 변경 시 넘버링 좌표도 같은 비율로 옮겨 도면 위 위치를 유지한다."*
**우리는 이게 필요 없다.** 좌표가 이미 0~1 정규화라 배율이 바뀌어도 상대 위치가 유지된다.
불변식 #1 의 이득이 여기서 나온다. **좌표를 손대는 코드를 이식하지 마라.**

합성 결과는 페이지 객체에 넣지 않고 **별도 캐시**에 둔다 (`pageId → {scale, src}`).
저장 용량이 늘지 않게 하기 위함이다.

### F5-4. 도면 영역

`_calcFitRect` (F1 참조) 가 만드는 `imgLayout = { offX, offY, dW, dH }` 가 도면 영역이다.
A4 캔버스 안에서 **실제 도면 그림이 차지하는 사각형**.

용도: 도곽·범례를 도면 위에 겹치지 않게 배치하고, 결함 표기가 여백에 찍히는 것을 막는다.

## F6. 용역 구성 — 설정 메뉴 잘림

> *"동, 층.도면 화면 각 설정버튼 클릭시 화면부족으로 메뉴노출이 잘리는 현상 수정"*

`⋯` 메뉴가 컨테이너 경계에서 잘린다. 원인 후보:
- 조상 요소의 `overflow: hidden`
- 메뉴가 뷰포트 밖으로 나가는데 뒤집기(flip) 처리가 없음

**처방**: 메뉴를 **포털로 body 에 띄우고**, 뷰포트 경계를 넘으면 위/왼쪽으로 뒤집는다.
목록 마지막 행에서 특히 티가 난다.

## F7. 이전 용역 가져오기 — 결함까지 승계

> *"이전용역 가져오기 하면 결함도 전부 가져옴(대신 전차로 표시)
>  (나중에 전차에 사진입력→금차로 변경됨 기능 구현)"*

**S1 의 결정을 뒤집는다.** S1 은 `[전차 등록]` 을 동·층·도면 구조 복사까지로 제한했다
(결함 승계는 Phase 2-D 본체라 반쪽으로 만들면 갈아엎는다는 판단).
사용자가 **지금 결함까지 가져오라**고 했으므로 범위를 넓힌다.

**이번에 하는 것**
- 이전 용역의 결함을 **전부 복사**
- 복사된 결함은 `status = PREV_PENDING` (전회차, **보라색**)
- `prevDefectId` 로 원본을 잇는다
- 좌측 리스트가 `전회차 N건 / 금회차 N건` 으로 갈린다
- 전회차 결함은 **기본적으로 출력에서 제외** (상세기획 §Phase 2-D 상태표)

**이번에 하지 않는 것** (사용자도 "나중에"라고 명시)
- 전회차 결함에 사진을 찍으면 금회차로 전환되는 흐름
- `[이전 상태]` 사진 슬롯 UI

단, **데이터 구조는 지금 그 전환을 받을 수 있게** 만든다.
`status` 3종(`PREV_PENDING` / `CURRENT` / `REPAIRED`)과 `prevDefectId` 는 이미 정의돼 있다.

## 작업 순서 권고

의존성과 위험도 기준.

| 순서 | 항목 | 이유 |
|---|---|---|
| 1 | **F3 좌표 숨김** · **F6 메뉴 잘림** | 작고 독립적. 먼저 끝내 커밋 |
| 2 | **F4 번호 풍선 항상 이동** | 히트 테스트 한 곳. 작지만 체감이 크다 |
| 3 | **S4 결함정보 입력 폼** | 본 작업. F3 이 자리를 비워둔 그곳에 붙는다 |
| 4 | **F2 도구 동작 정리** | 캔버스 상호작용 재배치. S4 와 겹치는 부분이 있다 |
| 5 | **F1 A4 정규화** | 도면 인입 파이프라인 변경. 기존 도면 영향 확인 필요 |
| 6 | **F7 전차 결함 승계** | 데이터 복사 범위 확대 |
| 7 | **F5 도곽·범례** | 새 기능. 출력(Phase 4)과 맞닿아 있어 마지막 |

**각 항목이 끝날 때마다 커밋한다.** 중간에 끊겨도 성과가 남아야 한다.
