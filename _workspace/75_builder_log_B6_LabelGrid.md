# B6 — P-2 번호풍선 격자 스냅 정렬

작업자: 리더 직접 · 브랜치 `feat/ui-behavior-0903` · 근거: **D28 · Q71(추천안 확정)**

---

## 달라지는 것

캔버스 상단 도구줄에 **`번호 정렬`** 버튼이 생긴다. 누르면 지금 열린 도면의 번호 풍선이
균일 격자에 맞춰 줄을 선다.

- **결함점(마크)은 안 움직인다.** 움직이는 것은 풍선뿐이고 지시선이 따라 늘어난다
- **Ctrl+Z 한 번**으로 정렬 전체가 되돌아간다
- 옮길 게 없으면 `이미 정렬돼 있습니다`, 대상이 없으면 `정렬할 번호가 없습니다`

## 확정 사항대로 만든 것

| 항목 | 결정 | 구현 |
|---|---|---|
| 격자 간격 | `balloonRadius × 2.5` (이미지 px) — Q71 ① A안 | `labelGridStepImgPx()`. **새 저장 필드 0개** |
| 대상 범위 | 지금 열린 도면 전체 — Q71 ② 가안 | `defectsOfDrawing` |
| 잠긴 결함 | **제외** — Q71 ③ | `!isLocked(d)` 필터 |
| 도면 밖 이동 | **안 한다** (D28 1차 제외) | 격자 스냅만 |

`labelScale`(도면별 번호 크기)이 이미 `balloonRadius` 에 반영돼 있어서, 번호를 키운 도면은
격자도 함께 넓어진다 — **도면마다 자동으로 맞고 사용자가 조절할 값이 안 생긴다.**

## 종횡비 함정을 어떻게 피했나

좌표는 0~1 정규화다(불변식 #1). 정규화 공간에서 균등 격자를 만들면 **도면이 가로로 길 때
격자가 가로로 늘어난 직사각형**이 된다. 그래서 코어 함수는 `stepX`·`stepY` 를 **따로** 받고,
호출자가 이미지 px 간격 하나를 `/iw`·`/ih` 로 나눠 넘긴다. 화면에서는 정사각 격자가 된다.

`iw`·`ih` 는 `state.canvas.drawing`(`DrawingRef`)에 이미 있다 — 어댑터가 따로 넣어 줄 필요가 없었다.

## 시작 위치는 저장값이 아니라 **그려진 위치**다

한 번도 안 옮긴 풍선(`placed=false`)은 `label.x/y` 저장값이 실제 자동 배치 위치와 다르다.
저장값에서 스냅하면 **눈에 보이는 것과 다른 곳으로 튄다** — C-2 에서 고친 것과 같은 함정이다.
그래서 `effectiveLabelNorm()` 으로 화면에 그려진 위치를 구해 거기서 스냅한다.
번호 문자열도 화면 렌더와 **같은 소스**(`displayNumbersOf`)를 넘긴다 — 넓어진 풍선만큼
자동 배치가 더 밀리기 때문이다.

## Undo 1스텝 — `ALIGN_LABELS` 커맨드 하나

`MOVE_LABEL` 을 N개 쌓지 않았다. 그러면 Ctrl+Z 를 결함 수만큼 눌러야 한다.
선례는 지우개(`DELETE_MEMO_PATH`)의 배치 payload 다.

한 커맨드가 여러 결함을 건드리므로 **저장 대기열도 고쳐야 했다** —
`defectTargetOf`(단수)만 쓰면 첫 결함만 디스크에 남는다. `defectTargetsOf`(복수)를 새로 만들고
`recordCommandWrites` 가 그걸 쓰게 했다. (지우개가 `memoTargetsOf` 로 같은 문제를 이미 풀어 뒀다)

## 겹침은 결정적으로 민다

두 풍선이 같은 격자점으로 반올림되면 하나는 빈 이웃 칸으로 밀린다. 밀리는 순서는
`격자 좌표 → defectId` 로 고정했다. **같은 입력이면 언제나 같은 그림**이 나온다 —
안 그러면 정렬을 두 번 눌렀을 때 결과가 달라져 보고서 재현이 깨진다. 테스트로 고정했다.

---

## ⚠️ 출력 재현성 — plan-reviewer 지적 확인 결과 **사실이다** (고치지 않았다)

`ExportRun` 은 **번호 매핑만 저장하고 풍선 좌표는 저장하지 않는다.**
따라서 정렬한 뒤 `[같은 번호로 다시 받기]` 를 하면 **번호는 같지만 풍선 위치가 다른**
조사위치도가 나온다.

이건 P-2 가 만든 문제가 아니라 원래 있던 성질이다 — 손으로 풍선을 하나 옮겨도 똑같이 벌어진다.
다만 정렬은 **한 번에 수십 개를 옮기므로 눈에 확 띈다.**
`ExportRun` 에 좌표를 넣는 것은 저장 스키마 변경이라 이번 범위 밖으로 뒀다. **판단이 필요하다.**

## 직접 확인해주실 것

1. 결함을 여러 개 흩어 놓고 **`번호 정렬`** → 번호가 격자에 맞춰 줄을 선다
2. **결함점(빨간 점·화살표)은 안 움직인다.** 지시선만 늘어난다
3. **Ctrl+Z 한 번** → 전부 원래 자리로 (⚠️ 여러 번 눌러야 하면 실패)
4. **전회차(보라)·보수완료(회색) 번호는 안 움직인다**
5. 한 번 더 누르면 `이미 정렬돼 있습니다`
6. **번호 크기(`labelScale`)를 150% 로 키우고** 정렬 → 격자 간격도 함께 넓어진다
7. **세로로 긴 도면**에서 정렬 → 격자가 찌그러지지 않고 정사각으로 보인다
8. 정렬 후 **새로고침** → 옮긴 위치가 그대로 남아 있다 (저장 대기열 보정 확인 — 첫 결함만 남으면 실패)
9. 정렬 후 **조사위치도 출력** → 캔버스에서 본 배치와 같다
