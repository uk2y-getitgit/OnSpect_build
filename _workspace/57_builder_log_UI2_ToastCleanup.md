## 미완료 / 막힌 것

없음. 다만 아래 3건은 **판단을 미루고 그대로 뒀다** (QUESTIONS.md Q62 · 비차단):

| 남은 토스트 | 왜 애매한가 |
|---|---|
| 색을 바꿨습니다 / 색을 상태 기본값으로 되돌렸습니다 | 성격은 "성공 확인"인데 스코프 제거표에 없다 |
| 표기 크기가 변경되었습니다 | **같은 함수**의 "표기 위치가 변경되었습니다"는 표에 있어 제거했다. 위치는 조용·크기는 토스트 — 일관성이 깨져 보일 수 있다 |
| 그리기 N획 대기 중 | 성공 확인이 아니라 **대기 상태 안내**로 판단해 유지 (화면만 봐선 대기 중인지 모른다) |

지시가 "스코프 문서 성공 확인 표에 속한 것만 제거"였으므로 표를 그대로 따랐다.
셋 다 제거를 원하시면 `interaction.ts` 3줄 삭제로 끝난다.

## 직접 확인해주실 것

1. **표기 생성** → 도면에서 점·영역·방향을 만든다 → 화면 하단에 아무 팝업도 안 뜨고,
   새 표기와 번호만 그 자리에 그려지면 정상 (선택 상태로 잡히고 패널이 열리는 것도 그대로)
2. **이동·크기** → 표기·번호 풍선·메모·그리기 획을 끌어 옮긴다 → 팝업 없이 그 자리로 옮겨지면 정상.
   ※ **크기 조절만 아직 "표기 크기가 변경되었습니다"가 뜬다** (Q62 — 이것도 없앨지 알려주세요)
3. **되돌리기가 살아 있는지(중요)** → 위 1·2를 한 뒤 상단 [되돌리기] 또는 `Ctrl+Z` →
   방금 한 생성·이동이 **정상적으로 취소되면** 커맨드가 안 빠진 것이다
4. **삭제는 여전히 알려주는지** → 결함·메모·그리기를 지운다 → 하단에 "…삭제되었습니다" +
   되돌리기가 **그대로 떠야** 정상 (여긴 안 뜨면 버그다)
5. **안 되는 이유는 여전히 알려주는지** → 도면 밖에서 드래그 시작, 8px 미만 짧은 드래그,
   전회차 표기 삭제 시도 → 경고 팝업이 **그대로 떠야** 정상
6. **색 변경** → 색을 바꾼다 → 아직 "색을 바꿨습니다"가 뜬다. 이것도 없앨지 알려주세요 (Q62)

  클릭을 막지도 않는다(`styles.css:1270`). 실제 화면은 위 체크리스트 1번에서 확인 부탁드린다.
