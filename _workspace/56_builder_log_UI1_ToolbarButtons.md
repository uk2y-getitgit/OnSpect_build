### 남긴 것 (일부러)

- **구 228행의 구분선은 유지했다.** 이제 `색상 / (영역이면 실선·채움)` 묶음과
  `스타일 초기화 / 번호 초기화 / 삭제` 묶음을 가르는 역할을 그대로 한다.
  최종 배치: `색상 [실선] [채움] │ 스타일 초기화 · 번호 초기화 · 삭제`.
- **`KIND_LABEL` 상수는 남겼다.** 버튼에서는 빠졌지만 툴바 루트의
  `aria-label={`${defect.seq}번 ${KIND_LABEL[type]} 표기 도구`}` 가 계속 쓴다.
  지우면 스크린리더가 "몇 번 무슨 표기인지" 를 잃는다.
- **`.ctx-toolbar__caret` CSS 는 남겼다.** 영역 테두리모양 드롭다운(`▾`)이 계속 쓴다.
- `ContextToolbarProps` 는 **한 글자도 안 바꿨다.** 제거한 3개는 전부 핸들러가 없던 자리표시자라
  호출부(`CanvasRoute.tsx:895`)에 영향이 없다.
