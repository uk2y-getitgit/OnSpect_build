## 1. 공통사항

- **C-1 화살표 축척 통일** — 첫 지시선 길이에 따라 화살표(머리) 크기가 생성되는데,
  도면 축척에 따라 고정 필요.
- **C-2 결함 이동 스냅 조정** — 말풍선 크기조절 시 영역이 보이는 것과 다름.
  *(사용자: 직접 확인 필요)*
- **C-3 규모 — 면적 직접입력 삭제** — 면적 선택 시 가로×세로 입력이 기본값.
  면적 직접입력은 거의 안 쓸 것 같아 삭제하고, 가로×세로에 따른 면적값만 노출.
- **C-4 영역선택** — 선택 활성화 → 더블클릭 + 드래그(영역선택).
  여러 결함을 삭제하거나 이동할 때 사용.
- **C-5 ⭐중요 — 말풍선 종류 선택** — 생성된 말풍선의 종류를 고를 수 있어야 한다
  (결함 / 신규 / 보수완료). 종류에 따라 색상 자동변경:
  **결함=빨강 · 신규=보라 · 보수완료=파랑**
  > ⚠️ 확정 규칙과 충돌 — QUESTIONS.md Q63 참조.

## 2. PC 버전

- **P-1 불러온 도면 크기조절** — 이미지 크기에 따라 여백이 너무 많거나 적다.
  사용자가 이미지 축척 값을 조절바로 수정.
- **P-2 번호풍선 자동정렬** — 보고서용. 주변 결함 위치 말풍선과 위치 정렬,
  가능하면 도면 밖으로 이동 등. 세부적인 건 사용자 조정.

## 3. 태블릿 버전

우측 사이드바 결함정보 입력을 현장에 맞게 단순화:

| # | 항목 | 요구 |
|---|---|---|
| T-1 | 조사구분 | **외관조사 고정**, 화면에서 숨김 |
| T-2 | 구조유형 | 노출 |
| T-3 | 부재 | **기둥·보·벽체·슬래브·마감재만** 노출 (나머지는 PC에서 세부수정) |
| T-4 | 구조체여부 | 숨김 |
| T-5 | 규모 | 지금과 동일하게 노출 |
| T-6 | 발생원인·보수보강방안·위치보조·메모 | 숨김 |
| T-7 | 사진메뉴 | **가장 상단으로 이동.** 사진이 삽입될 미리보기 칸을 만들고 그 칸 자체가 사진추가 버튼. 사진이 1개 추가되면 사진추가 박스 **우측으로** 사진 삽입 |
| T-8 | 사이드바 크기조절 | 캔버스↔사이드바 경계선을 **1초 이상 누르면** 좌우 크기조절. 사이드바 내용은 크기에 따라 UI 최적화(줄바뀜, 버튼·박스 크기, 사진 크기 등) |
| T-9 | 미니맵 | 캔버스 우측하단 미니맵 **숨김** (사용 안 함) |
