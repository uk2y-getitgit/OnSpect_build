### 경계

- **DB 마이그레이션 0.** `DB_VERSION` 1 그대로. 새 오브젝트 스토어·인덱스 없음 — `ExportRun` 은 `meta` KV 재사용(K2)
- **`openDb()` 를 화면에서 부르지 않는다** (검수 경미 6). `IdbProjectRepo` 에 위임 메서드 6개
  (`putExportRun`·`getExportRun`·`listExportRuns`·`appendExportArtifact`·`pruneExportRuns`·`deleteExportRun`).
  UI 는 `storage.repo.xxx()` 만 부른다
- **`project-core/export/*` 는 라이브러리를 모른다.** 엑셀 호출은 `apps/web/src/export/xlsx.ts` 한 파일뿐이고 `await import()` 로 동적 로드된다 → **번들에서 분리됐다**(아래 빌드 결과 확인)
- **PDF 라이브러리 0.** 브라우저 인쇄(K1 · Q32)
- `canvas-core` import 없음(`damageTable.ts`·`photoBook.ts` 는 로컬 최소 타입 `DamageDefect`·`PhotoBookDefect` 로 구조적 타이핑)
- `ui/defectForm/*` 을 건드리지 않았다

### 번호가 어긋나지 않게 하는 구조 (K20)

```
Export.tsx  ──planExport()──►  ExportPlan.rows  ──┬─► damageTableModel
                                                  ├─► defectListModel
                                                  ├─► photoBookModel
                                                  └─► locationMap displayNumbers
                                    │
                                    └─► ExportRun.mapping 으로 저장
                                            │
PrintRoute  ──planFromRun()──►  같은 rows ───┘   (재계산 없음)
```
4종이 **같은 `rows` 배열 하나**를 본다. 각자 `assignNumbers` 를 부르지 않는다.

### 선택 하이라이트가 출력에 새지 않는다

`locationMap.ts` 의 `RenderInput` 에서 `selection`·`hover`·`guides`·`preview`·`dragDefectId`·
`ghost`·`pending` 을 **전부 비운다**. 이게 빠지면 마지막으로 고른 결함에 파란 테두리가
보고서에 인쇄된다.

- [ ] ⭐ `[해제]` → 아무 순서로나 다시 누르면 **누른 순서대로 배지 번호가 붙고** 구간도 그 순서로 매겨지는가
