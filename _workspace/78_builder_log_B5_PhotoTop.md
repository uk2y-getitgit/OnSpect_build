# B5 — T-7 사진메뉴 최상단 + 추가 타일

작업자: 리더 직접 · 브랜치 `feat/ui-behavior-0903`

---

## 달라지는 것 (태블릿에서만)

### 1. 사진이 폼보다 **위**로 올라간다
결함을 찍으면 사진부터 붙이는 순서라, 폼 아래에 있으면 매번 스크롤해야 했다.
PC 는 §2-5 대로 **폼 아래 그대로** 둔다.

### 2. 그리드 첫 칸이 곧 `+ 사진 추가` 버튼이다
사진이 들어갈 자리를 미리 보여주고, 그 칸을 누르면 사진을 고른다.
썸네일과 **같은 크기·같은 그리드 칸**이라, 사진이 한 장 늘 때마다 자연스럽게 **오른쪽으로** 채워진다.

```
[ + 사진추가 ] [ 사진1 ] [ 사진2 ] [ 사진3 ] …
```

사진이 0장이어도 이 칸은 떠 있다 — "아직 사진이 없습니다" 문구 대신 누를 면이 보인다.
손가락으로 누를 곳이 상단의 작은 버튼 하나뿐이면 현장에서 놓치기 쉽다.

상단의 `촬영` · `+ 사진 추가` 버튼은 **그대로 남겨 뒀다.** 촬영(카메라)은 추가 타일과
동작이 다르고(한 장씩), 두 문을 다 열어 두는 편이 현장에서 안전하다.

## 잠금 규칙은 그대로다

추가 타일도 기존 `addDisabled` 를 그대로 본다 —
보수완료 표기에는 사진을 못 붙이고, 전회차 표기에는 붙일 수 있으며 붙이면 금회차로 전환된다(G-8).
`title` 문구도 상단 버튼과 같은 갈래를 쓴다.

## 직접 확인해주실 것

1. **태블릿(`/tablet`)에서 결함 선택** → 사진 섹션이 결함정보 폼 **위**에 있다
2. 사진 0장 → 점선 `+ 사진 추가` 타일이 하나 보인다
3. 그 타일을 눌러 사진 1장 추가 → **타일 오른쪽에** 사진이 붙는다
4. 여러 장 추가 → 타일은 늘 맨 앞, 사진이 오른쪽으로 채워진다
5. **PC** → 사진 섹션이 예전처럼 폼 **아래**에 있고, 추가 타일은 안 보인다 (⚠️ PC 는 안 바뀌어야 한다)
6. **보수완료 표기**에서 추가 타일이 흐리게 비활성이고 이유가 뜬다
7. **전회차 표기**에서 타일로 사진을 붙이면 금회차(빨강)로 전환된다
