### 렌더 · 뷰포트 (T2 · T3)
- 지하3층 도면(2400×1600)이 Fit 상태로 뜬다. 통심선·기둥·해칭 벽체·치수선이 선명하다 → `shot02.png`
- 창을 1631 → 900 → 760px 로 줄여도 **가로 스크롤이 생기지 않는다.** 라벨이 한 줄로 유지되고 넘치면 말줄임(`— 결함유형 미…`) → `shot10-900.png`
  - 760px 에서 좌측 패널이 사라지지 않고 캔버스를 밀어내는 **레이아웃 붕괴 버그를 발견해 고쳤다**(CSS 특이도). 수정 후 재확인: `stage 520px`, 가로 오버플로 없음
- 휠 줌 후 커서 아래 지점이 고정된다(단위테스트) / 화면에서 43% → 47% → 133% 로 변한다
- **`Ctrl`+휠이 브라우저 페이지 확대를 일으키지 않는다** (`defaultPrevented === true` 확인, 캔버스만 43→47%)
- 빈 곳 더블클릭 → Fit(133% → 43%)
- 중클릭 드래그 팬: 커서 `grabbing`, 줌 배율 변화 없음
- 층을 바꿨다 돌아오면 **보던 배율·위치가 유지**된다 (단위테스트 + 화면)

| 2 | Tab 키만으로 화면 전체를 돈다 | **통과.** 포커스 가능한 18개 요소 전부에 `outline 2px solid #2d6cdf` 확인. 순서는 상단바 → 층 → 결함 → 캔버스 → 팔레트. 접근 이름이 없던 확대/축소 버튼(`BUTTON` 으로만 읽힘)을 발견해 `aria-label` 추가 |
| 3 | 창 폭 1280 → 900 → 좁게 | **통과(수정 후).** 760px 에서 좌측 패널이 캔버스를 밀어내는 버그를 발견·수정. 지금은 어느 폭에서도 가로 오버플로 0, 라벨 깨짐 0 |
| 4 | 가장 긴 항목명을 넣어본다 | **통과.** `계단참 슬래브` · `벽(비구조체)` · `마감박리/박리` 를 픽스처에 넣었다. `word-break: keep-all` 로 한글 단어 중간이 잘리지 않고, 좁아지면 어절 유지 + 말줄임 + `title` 툴팁 |
| 5 | 모든 버튼을 눌러본다 | **통과.** 상단바 4개(패널 접기·축소·확대·전체 맞춤), 팔레트 2개, 층 4개, 인스펙터 2개, 툴바 2개, 메뉴 1개 — 전부 눌러 **콘솔 에러 0건**. `선택` 버튼만 "이미 선택됨" 이라 변화 없음(정상). 비활성 버튼은 전부 `cursor: not-allowed` + 이유가 담긴 툴팁 |
| 6 | 빈 데이터로 열어본다 | **통과.** `지하1층`(결함 0건) → 좌측·캔버스 양쪽에 안내 → `shot08.png`. `지상1층`(도면 없음) → `이 층에 등록된 도면이 없습니다` + `[도면 등록]`, 팔레트·줌 전부 비활성 → `shot09.png`. 초기 문구가 도면 없는 층에도 "점 도구를 켜고" 라고 안내하던 것을 발견해 분기 |

### 자가 점검 중 발견해 고친 것 (5건)
1. 좁은 폭에서 좌측 패널이 캔버스를 밀어냄 (CSS 특이도)
2. 컨텍스트 툴바가 선택된 결함의 마크를 덮음
3. 확대/축소 버튼에 접근 이름 없음
4. 도면 없는 층에서 좌측 빈 상태 문구가 틀림
5. 옛 토스트의 `[되돌리기]` 가 최신 조작을 취소함 → 최신 토스트에만 남기도록 수정
